# KRX 공식 휴장일 등록 → 예상 지급일 자동 재계산 (account-uat 격리 전용)
1. KRX가 연도 휴장일을 공표하면 `<연도>.json` 파일을 이 폴더에 추가: {"year":2027,"source":"KRX 공지 (날짜·URL)","holidays":{"2027-01-01":"신정", ...}} (주말 제외 휴장일 전부)
2. 저장소 루트에서 `python3 account-uat/tools/fd_gen.py` 실행 (2028년 이후 추정 계산이 필요하면 python-holidays==0.106 설치)
3. 결과: account-uat/fd-calendar.json의 해당 연도 status=official, fd-forecast.json의 해당 연도 예상 지급일 재계산·라벨 '추정' 해제. 실제 지급일·기존 3,416건·원장·CORE는 읽기만 하며 변경 없음(자가검증 3416/3416 출력)
4. 변경된 두 JSON만 커밋 (메인 사이트·auto-test 무관). 원클릭 워크플로 파일은 토큰 권한상 수정 불가 → 이 수동 1명령이 재계산 경로
검증 기록: 2027 가상 공식 파일(가상 휴장일 2027-11-02 포함) 등록 시험 → 2027 status official, 지급일 121건 이동(예: 0000D0 11-02→11-03), 라벨 2,085건 공식 전환, 파일 삭제 후 원상 복귀
